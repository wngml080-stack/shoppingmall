# 상품 상세 페이지 레이아웃 수정 계획

## 📋 개요

상품 상세 페이지(`app/products/[id]/page.tsx`)의 레이아웃을 2열 구조로 재구성합니다.

## 🎯 목표

- 화면을 2열로 나누기
- 왼쪽 열: 제품 이미지
- 오른쪽 열: 상품 정보를 순서대로 배치

## 📐 레이아웃 구조

### 전체 구조
```
┌─────────────────────────────────────────┐
│  뒤로가기 버튼                            │
├──────────────┬──────────────────────────┤
│              │  제품 이름                │
│   제품 이미지 │  가격                    │
│              │  재고 표시                │
│              │  카테고리                 │
│              │  상품 설명                │
│              │  등록일                   │
│              │  [장바구니 버튼]          │
└──────────────┴──────────────────────────┘
```

### 오른쪽 열 정보 순서 (위에서 아래로)

1. **제품 이름** (큰 제목 스타일)
   - `text-3xl md:text-4xl font-bold`
   - 큰 제목 스타일

2. **가격** (천 단위 콤마 포맷팅)
   - `text-4xl md:text-5xl font-bold`
   - 한국 원화 포맷 (₩)

3. **재고 표시**
   - 품절: 빨간색 텍스트
   - 남은 수량 < 10개: 주황색 텍스트
   - 재고 있음: 초록색 텍스트

4. **카테고리 태그**
   - 작은 태그 스타일 (rounded-full)
   - 회색 배경

5. **상품 설명**
   - 제목: "상품 설명"
   - 본문: 줄바꿈 지원 (`whitespace-pre-line`)

6. **등록일**
   - 작은 회색 텍스트
   - 한국어 날짜 포맷

7. **장바구니 추가 버튼** (하단)
   - 품절 시 비활성화
   - 전체 너비 버튼

## 🔧 구현 작업

### 1. 현재 상태 분석

**현재 구현된 순서:**
- 카테고리 → 상품명 → 가격 → 재고 → 상품 설명 → 등록일

**수정할 순서:**
- 상품명 → 가격 → 재고 → 카테고리 → 상품 설명 → 등록일

### 2. 수정 작업

#### 2.1 정보 순서 재배치
- 오른쪽 열(`<div className="flex flex-col justify-between">`) 내부의 요소 순서 변경
- `80-138줄` 영역의 JSX 구조 재정렬

#### 2.2 스타일 유지
- 기존 스타일 클래스는 그대로 유지
- 반응형 디자인 유지 (`grid-cols-1 md:grid-cols-2`)

### 3. 코드 구조

```tsx
{/* 오른쪽 열: 상품 정보 */}
<div className="flex flex-col justify-between">
  <div>
    {/* 1. 제품 이름 */}
    <h1>...</h1>
    
    {/* 2. 가격 */}
    <p>...</p>
    
    {/* 3. 재고 표시 */}
    <div>...</div>
    
    {/* 4. 카테고리 태그 */}
    <span>...</span>
    
    {/* 5. 상품 설명 */}
    <div>...</div>
    
    {/* 6. 등록일 */}
    <div>...</div>
  </div>
  
  {/* 7. 장바구니 버튼 (하단 고정) */}
  <div>...</div>
</div>
```
